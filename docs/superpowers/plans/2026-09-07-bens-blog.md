# Ben's Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy a minimal, Markdown-authored blog named Ben's Blog at `blog.gbyb.de`, with GitHub Discussions comments through Giscus.

**Architecture:** Astro statically renders validated Markdown content into HTML at build time. A focused layout/component layer supplies navigation, theme behavior, article presentation, RSS, tags, and Giscus; Cloudflare Pages rebuilds from the `main` branch.

**Tech Stack:** Astro 5, TypeScript strict mode, Astro Content Collections, MDX, `@astrojs/rss`, Vitest, Cloudflare Pages, Giscus.

**Spec:** `docs/superpowers/specs/2026-09-07-bens-blog-design.md`

## Global Constraints

- Use TypeScript strict mode.
- Keep content as Markdown files in `src/content/blog/`.
- Do not add a database, API, custom account system, analytics, newsletter, search service, or editor dashboard.
- Giscus must appear only on individual post pages and gracefully fall back to a readable link when scripts fail.
- Build command is `npm run build` and Cloudflare Pages output directory is `dist`.
- Do not modify `.env` files.
